Phase 1 — Preparation
Step 1: Compile taxalist of aquatic macroinvertebrates occurring in Lithuania from literature and other sources
Step 2: Validate and correct taxonomy against GBIF and Molluscabase backbones
Step 3: Specialists and practitioners are provided only validated taxa at the species level and asked to state the taxonomic level to which they can identify each species
Step 4: Flag taxa excluded from EQR calculations using the excluded_taxa sheet as the source of truth. Entirely excluded groups (all families excluded): Porifera, Cnidaria, Nematoda, Nematomorpha, Nemertea, Bryozoa (phyla); Polychaeta, Arachnida, Collembola, Maxillopoda, Branchiopoda (classes); Stylommatophora, Dolichomicrostomida, Prolecithophora, Rhabdocoela, Anostraca (orders). Additional excluded families: Coreidae, Gerridae, Hydrometridae, Mesoveliidae, Veliidae, Chrysomelidae, Curculionidae, Succineidae, Clausiliidae, Geoplanidae, etc. These taxa are retained but marked as excluded.
Phase 2 — Forced-level assignments
Taxa whose OTU level is fixed regardless of specialist agreement. These taxa skip Phases 3 and 4 — the Phase 4 metric-compliance check is not applied to forced-level entries. Phase 2 acts as a ceiling override (caps the OTU level).
2.1 — Entirely excluded groups

All families in excluded_taxa → OTU at group level:
• Entirely excluded phyla → phylum (e.g., Porifera Gen. sp.)
• Entirely excluded classes → class (e.g., Polychaeta Gen. sp.)
• Entirely excluded orders → order (e.g., Stylommatophora Gen. sp.)
2.2 — Oligochaeta

NOT excluded from EQR
• Naididae → family (Naididae Gen. sp.)
• All other Oligochaeta → subclass (Oligochaeta Gen. sp.)
Includes order-level entries: Crassiclitellata, Enchytraeida, Lumbriculida, Tubificida
2.3 — Neuroptera

NOT excluded from EQR
• All entries forced to family
• Osmylidae → Osmylidae Gen. sp.
• Sisyridae → Sisyridae Gen. sp.
Specialist agreement at order was too coarse
2.4 — Stenostomidae

Excluded from EQR
Forced to phylum → Platyhelminthes Gen. sp.
Order taxonomically unavailable

Excluded from EQR
Any taxon excluded but NOT in an entirely excluded group → family level
Talitridae, non-Asellidae Isopoda, Neomysis/Praunus, Crangonidae/Palaemonidae, Hemiptera excl. families, Lepidoptera excl. families, etc.
Phase 3 — 100% specialist agreement (species-level entries only)
For each species-level taxon not assigned in Phase 2, determine the 100% specialist agreement level — the coarsest level assigned by any specialist. No specialist’s assessment is discarded.
Assign OTU at the 100% agreement level
Higher-level entries — genus, family, and above
Family, order, subclass, class, and phylum entries are structural fallback entries. They accommodate damaged, juvenile, or poorly preserved specimens and are always assigned at their own taxonomic level.
Family → family
e.g., Baetidae Gen. sp.
Order → order
e.g., Ephemeroptera Gen. sp.
Subclass / class / phylum → respective level
Truly aquatic rule (order+ entries): Only truly aquatic groups keep order-and-above entries for EQR calculations: Bivalvia (class), Plecoptera, Ephemeroptera, Odonata, Megaloptera, Trichoptera (orders). All other groups’ order+ entries are excluded from EQR.
Genus entries are metric-minimum-aware, capped at genus. The metric minimum is determined by the genus’s own taxonomy (group, family), NOT inherited from species-level BMWP exceptions:
• If the genus has a forced-level override (Phase 2) → resolves to the forced level (e.g., Talitridae genus → Talitridae Gen. sp.)
• If the minimum is genus or finer → genus entry stays at genus level (e.g., Leuctra sp. — Plecoptera min = genus)
• If the minimum is coarser than genus → genus entry resolves to that coarser level (e.g., Baetis → Baetidae Gen. sp. — Ephemeroptera min = family)
• If no metric group → genus entry defaults to genus level
• Genus entries in entirely excluded groups collapse to the group-level OTU
Subspecies entries (e.g., Nemoura cinerea subsp. cinerea) that are not present in the Specialist_taxalist inherit their OTU assignment from the parent species. This prevents subspecies from collapsing to a coarser fallback level when the parent species has a known specialist agreement.
Phase 4 — Metric compliance check (species-level entries only, applied after Phase 3)
For each species-level taxon, verify that the OTU level from Phase 3 meets or exceeds the minimum identification requirement for its group (see reference table below). If the taxon’s group has no specific metric requirement, this check is automatically passed.
Does the assigned OTU level meet or exceed the minimum metric requirement?
Yes
OTU assignment is confirmed.
No
Override: adjust the OTU level to the minimum level required by the relevant metric. Document the override with the reason.
(e.g., “100% agreement = family; overridden to genus because DSFI requires Leuctra at genus for IG1 placement”)
Overrides should be rare. Frequent overrides indicate a gap between practitioner capability and metric requirements.
Final output
Final OTL entry for each taxon:
Validated name · OTU level · OTU name (e.g., Baetis sp. / Baetidae Gen. sp.) · Taxonomic rank · Override flag (if applicable) · EQR exclusion flag (if applicable)
Hierarchical entries (both fine-resolution OTUs and coarser fallback entries) coexist in the taxalist, accommodating damaged, juvenile, or poorly preserved specimens.
